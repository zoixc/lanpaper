# Макет Lanpaper 2.0 — как этим пользоваться

Кликабельный прототип админ-панели. Это **стенд, а не код приложения**: ничего из
`design/` не отдаётся сервером, а каталог исключён из контекста сборки Docker.
Подробный разбор и план переноса — в [`../06-redesign-v2.md`](../06-redesign-v2.md).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Админка макета: шапка, фильтры, сетка, пульт ссылки, диалоги, настройки |
| `screens.html` | Витрина: тот же экран в трёх iframe — 1440 / 834 / 390 px, с переключателями темы, акцента и вида |
| `tokens.css` | Сброс, шрифты, пять палитр, светлая и тёмная темы, типографика, утилиты |
| `ui.css` | Компоненты: кнопки, чипы, поля, карточка медиа, панель, диалоги, тосты, скелетоны |
| `layout.css` | Каркас: липкая шапка, строка фильтров, сетка, подвал, плавающая кнопка, адаптивность |
| `i18n.js` | Строки RU/EN (194 ключа в каждом языке) |
| `data.js` | 20 демо-ссылок в формате `/api/wallpapers`, 11 файлов сервера и конфигурация из ручек приложения |
| `app.js` | Вся интерактивность: рендер, фильтры, пульт, диалоги, тосты, выбор пачкой, горячие клавиши |
| `tools/check.mjs` | Проверка контраста палитр (без зависимостей) |
| `standalone.html` | Тот же макет одним файлом: CSS, скрипты, шрифты и кадры внутри |
| `tools/build-standalone.py` | Сборка `standalone.html` (нужен Pillow) |

## Как посмотреть

```bash
cd design && python3 preview.py     # http://localhost:8000/
```

- `/design/v2/index.html` — сам макет.
- `/design/v2/screens.html` — три ширины рядом, с общим переключателем темы и акцента.

Состояние можно задать адресом:
`v2/index.html?theme=dark&palette=clay&view=list&lang=en&fail=1`
(`embedded=1` отключает задержку скелетона — так витрина грузит кадры мгновенно,
`fail=1` показывает состояние «сервер не ответил»). Параметры важнее сохранённых
настроек, но в браузере не запоминаются.

## Что можно потрогать

- Клик по карточке → **пульт ссылки**: вкладки «Медиа», «Версии», «Плейлист», «Доступ».
- «⋯» на карточке → открыть, скопировать URL, переименовать, закрепить, доступ, удалить.
- «＋ Новая ссылка» (на телефоне — плавающая кнопка) → диалог с проверкой ID; после
  создания тост предлагает сразу загрузить файл.
- Поиск, фильтры (Фото / Видео / Плейлисты / Закреплённые / Доступ), сортировка — со счётчиками.
- Библиотека идёт порциями по 12 карточек: «Показать ещё» с остатком и «видно 12 из 20»
  рядом со счётчиком в шапке.
- Вид «список» на десктопе — настоящая строка: кадр слева, справа одной линией имя,
  мета, метки и **переключатель уровня доступа** (метка доступа в этом виде не
  рисуется — она бы дублировала переключатель). На телефоне переключателя нет:
  строка узкая, о доступе говорит метка.
- «Заменить» предлагает три пути: **с телефона**, **по ссылке** (адрес проверяется) и
  **из файлов сервера** — галерея с превью, размерами кадра и весом.
- Вкладка «Версии» всегда показывает занятое место и бюджет истории, «Плейлист»
  предупреждает о пределе: «Плейлист заполнен: до 8 файлов».
- Режим выбора (`s`) → панель массовых действий: закрепить, скопировать адреса, удалить.
  Смены уровня доступа пачкой здесь нет — обсуждалась и отклонена (см. 11-бис
  в `../06-redesign-v2.md`).
- Настройки → тема, акцент, язык, данные, обслуживание, горячие клавиши.
  В списке языков шесть, как в приложении, но переведены только русский и
  английский: выбор непереведённого честно об этом сообщает.
- Перетащите файл в окно: ссылки создадутся по именам файлов и окажутся на виду.
- Горячие клавиши: `/` поиск, `n` новая ссылка (и `Ctrl/⌘ N`), `t` тема, `g` вид,
  `s` выбор, `Ctrl/⌘ F`, `Ctrl/⌘ G`, `Ctrl/⌘ T`, `Esc` закрыть.
- Без сервера: `?fail=1` показывает состояние ошибки с кнопкой «Повторить».

## Версия одним файлом

`standalone.html` — та же страница, но без внешних запросов: стили, скрипты,
шрифты и девять демо-кадров вклеены внутрь (790 КБ). Нужна там, где открывается
один файл и соседние каталоги недоступны, — например в просмотрщике или при
отправке макета в переписке.

```bash
python3 -m venv .venv && .venv/bin/pip install pillow
.venv/bin/python design/v2/tools/build-standalone.py     # 790 КБ, 0 внешних ссылок
```

Собирать заново после каждой правки `index.html`, `*.css` или `data.js`: файл
не обновляется сам. Кадры ужимаются до 900 px и перекодируются (JPEG q80, PNG
с прозрачностью), поэтому в сборке они весят 362 КБ вместо 878 КБ исходных.

## Проверки

```bash
node design/v2/tools/check.mjs           # контраст: 120 пар, 0 провалов
node design/v2/tools/check.mjs --table   # то же с числами по каждой паре
node --check design/v2/*.js              # синтаксис
```

В песочнице дополнительно гоняется jsdom-тест на 143 утверждения (поведение
интерфейса) — по странице макета и по `standalone.html`, — проверка правил
`layout.css` (то, что jsdom не умеет: медиазапросы и специфичность), а также
`html-validate` и `stylelint`. Сами тесты в репозиторий не попадают, результаты описаны в
`../06-redesign-v2.md`. **Пиксели так не проверить:** внешний
вид нужно смотреть в настоящем браузере — jsdom не рисует, и именно на этом
провалился перенос 0.13.0.

## Как править

- Меняете палитру — правьте блоки в `tokens.css` и сразу гоняйте `tools/check.mjs`:
  текст на фоне, на карточке и на акцентной кнопке должен остаться ≥ 4.5:1.
- Меняете раскладку — держите одну разметку на все ширины. Ломать каркас можно
  только внутри медиазапросов в `layout.css`; безусловное правило перебьёт
  мобильное (на этом ломались прошлые попытки).
- Правило, которое должно побеждать сетку, усиливайте вторым классом
  (`.grid.grid--list`): селектор из одного класса проиграет любому медиазапросу
  ниже по файлу — так вид «список» и оставался сеткой. За этим следит
  `css-check` в песочнице.
- Новые строки — в оба языка `i18n.js`; ключи называйте по-английски, как в
  `static/i18n/*.json`, чтобы перенос в приложение был механическим.
