# Studio 0.19.0 — стенд и история макетов

**Studio перенесён в основное приложение.** Стенд `/admin?design=studio` теперь
использует `static/css/studio.css` и `static/js/studio-layout.js`, а не старые
`radical.js`/`studio.js`. Файлы макетов 01/02/03 ниже сохранены для сравнения;
правки production нужно делать в `static/`, не в архивных слоях.

Видео в сетке обозначено значком; настоящий MP4/WebM загружается по нажатию в
пульте. Стенд использует маленькие синтетические файлы из `tests/e2e/fixtures`
(есть портретное видео). GIF-превью статично; открытие оригинала сохраняет
анимированный файл. Демо по-прежнему read-only, с отдельными настройками и без
PWA. Только проверки через Go-сервер подтверждают auth/CSP/Range/загрузку файлов.

Основные проверки описаны в `docs/STUDIO_QA.md` и `docs/STYLE_GUIDE.md`.

## Архив: исходный интерактивный макет


```sh
node design/mono/server.mjs
# http://localhost:8080/admin
```

`PORT=8090 node design/mono/server.mjs` меняет порт. Сервер слушает `0.0.0.0`
для просмотра через прокси. Это **только dev-сервер**, не публичный deployment.

Используются текущие `admin.html`, `static/css/style.css` и JS-модули приложения.
Новый дизайн — отдельный слой `design.css`, не замена боевого CSS.
Верхняя полоска LP / LAB — управление стендом, не часть предлагаемого интерфейса:
переключает исходный/новый дизайн и одну/13 ссылок с сохранением параметров URL.

Работают клиентские поиск, фильтры, сортировка, плитка/список, темы, меню и панели.
API — демонстрационный, только для чтения. Создание, загрузка, изменение, удаление
и операции с сессиями отклоняются явно; реальные данные не читаются и не меняются.
Медиа взяты из `design/prototypes/media`, новых внешних запросов нет.

Настройки демо изолированы ключом `lp-mono-demo`; регистрация service worker
выключена в отдаваемой копии app.js. Исходные файлы приложения не переписываются.
Стенд намеренно не воспроизводит серверную авторизацию, CSP или обработку медиа;
его задача — оценка оформления, не проверка этих механизмов.

Шрифт заголовков Literata 600: @fontsource/literata 5.3.0, SIL OFL,
лицензия в `fonts/OFL.txt`. Два локальных WOFF2 (латиница/кириллица), `font-display: swap`.
Остальной интерфейс использует существующий Golos Text.

## Каталог / 02 — радикальная композиция

`/admin?design=radical&sample=collection` — боковая навигация, поиск в верхней
строке, крупная редакционная типографика, изображения без рамок с нумерацией.
Первый кадр на широком экране занимает две колонки; на планшете сетка равномерная.
На телефоне боковая панель становится верхней навигацией с прокруткой фильтров.
`/` открывает именно эту версию; «Фотопринт / 01» и «Исходный» остаются в LP / LAB.

`radical.js` перемещает существующие DOM-узлы до запуска app.js, не дублирует
контролы или ID. `radical.css` меняет композицию поверх первого макета. Никакие
функции и API боевой панели не добавлены. Дополнительные подписи — только текст
макета; его локализация не является частью продакшен-переводов.

## Studio / 03 — компактное рабочее пространство

`/admin?design=studio&sample=collection` (теперь открывается с `/`).
Убраны крупный serif-заголовок и декоративные подписи. Заголовок и счётчик
перемещены в компактную строку рядом с поиском и видом. Настройки и тема —
внизу узкой навигации. Галерея равномерная, без большого первого кадра.
На телефоне все существующие контролы остаются доступны в верхних рядах.

`studio.js` выполняется после `radical.js` перед основным app.js. Это всё те же
DOM-узлы и обработчики, без копирования логики приложения.
`studio.css` подключается последним только для Studio. Предыдущие варианты
сохраняются. Manrope Variable (200–800), @fontsource-variable/manrope 5.3.0:
локальные латинский/кириллический WOFF2, лицензия `fonts/Manrope-OFL.txt`.

### Мобильная витрина

`/demo/mobile.html` — iframe с настоящим Studio / 03, ширина содержимого
360/390/430px (ограничена доступной шириной внешнего окна). Внутри скрыта только
полоска LP / LAB через `embedded=1`; функции панели и media queries не подменяются.
Можно открыть интерфейс без рамки по ссылке в витрине.

```sh
PORT=8081 DEMO_START=/demo/mobile.html node design/mono/server.mjs
```

Это просмотр адаптивной вёрстки, не эмуляция мобильного браузерного движка,
системного интерфейса телефона или touch-событий.

### Studio finish — единый стиль контролов

В конце `studio.css` — отдельный раздел `STUDIO FINISH`: радиусы 9/6px,
тонкие границы и тени, согласованные кнопки/меню/поля/сегменты, явный фокус,
disabled-состояния и reduced-motion. Ползунок плитка/список теперь использует
реальную ширину кнопки, а не старый круглый маркер 30px.
Компактная компоновка и размеры контролов Studio сохраняются одинаковыми на
десктопе и мобильных устройствах без искажений от `hover: none` / `pointer: coarse`.
Дополнительных скриптов/таймеров нет.

### Навигация, пульт и компактная сетка

Кнопка перед заголовком сворачивает навигацию, `aria-expanded` отражает состояние.
Выбор запоминается отдельно в `lp-studio-nav-collapsed`. При сворачивании
существующие кнопки создания, темы и настроек перемещаются в верхний ряд,
при разворачивании возвращаются обратно. ID/обработчики не дублируются.

Пульт ссылки и настройки используют Manrope, поверхности и размеры контролов
Studio. Сетка: колонки от 184px, кадр 16:10; на телефоне сохраняются две колонки.
Изображения в сетке/пульте вписываются целиком (`contain`), без обрезки при hover.
Шахматная подложка PNG и оригинальные заглушки видео/пустых ссылок сохранены.

В наборе из 13 ссылок теперь есть портрет, квадрат, панорама, PNG-иконка,
горизонтальное и вертикальное видео (только метаданные), пустая ссылка.
Размеры и байты картинок прочитаны из файлов в `media-dimensions.json`.
Видео не подменяется JPG: оригинальный код показывает тип/значок/длительность,
а открытие демо-видеофайла честно возвращает сообщение о его отсутствии.
Проверка реального воспроизведения и видеообработки требует настоящего сервера
и медиафайлов; этот макет этого не симулирует.

### Проверка списка, типографика и фон

- Миниатюры списка имеют стабильный кадр и абсолютно позиционированное
  изображение с `contain`: натуральная высота портрета не растягивает строку.
- Раскладка списка по умолчанию двухстрочная. Пять колонок включаются только
  при достаточной ширине самой библиотеки (`@container`), а не окна вместе
  с боковой панелью. Без container queries остаётся рабочая двухстрочная версия.
- В набор добавлены реальные WebP и двухкадровый GIF (`fixtures/`), изготовленные
  из существующего `wp-abstract.jpg`. PNG-иконка — RGBA. Видео остаётся метаданными.
- Manrope Variable единообразно применяется к полям, заголовкам и метаданным,
  цифры табличные. Добавлен локальный latin-ext; проверено покрытие всех букв
  файлов переводов ru/en/de/fr/es/it. Для других письменностей предусмотрен
  системный fallback, полного покрытия всех языков Manrope не обещает.
- Точечная фактура под библиотекой — статический CSS, без запросов и анимации;
  отключается в forced-colors и prefers-contrast: more.
- У поля создания/переименования убраны рамка и focus halo. Фокус показывают
  фон и нижняя линия; в forced-colors — системная линия. Валидация и aria-invalid
  сохранены. На остальных полях и кнопках фокус не отключался.

Проверка jsdom: список из 13 ссылок, JPG/PNG/GIF/WebP, разные пропорции,
обозначения MP4/WebM, пустой файл, иконки, пульт портрета, сворачивание навигации,
валидация имени. Это проверка DOM/логики, не pixel-diff и не проверка реального
мобильного движка или воспроизведения видео. GIF/WebP декодированы Pillow,
покрытие букв проверено таблицами cmap шрифтов.

### Текущее решение: штатная геометрия медиа + Studio

Последняя правка заменяет экспериментальные 16:10 и сплошной `contain`:
сетка использует брейкпоинты/минимальные ширины/отступы `static/css/style.css`,
кадр 16:9. Обычные горизонтальные фотографии заполняют кадр; портреты, квадраты
и PNG вписываются через штатный класс `card__media--contain` из `fitMode()`.
Ширины миниатюр списка также наследуются от основной панели (124/108/92px).
Стабилизация высоты изображений списка и его адаптация к боковой панели остаются.
Studio продолжает определять шрифт, цвета, форму и компоновку страницы, поэтому
фактическая ширина карточки зависит от доступной ширины библиотеки, как обычно.

При ≤760px иконка навигации повёрнута на 90° по часовой стрелке. Отражение
стрелки при сворачивании сохраняется; на десктопе ориентация не изменена.
Проверки синхронизации геометрии с основной панелью и обеих ориентаций:

```sh
npm ci --prefix tools --ignore-scripts
node --test design/mono/media-contract.test.mjs
```

### Наборы ссылок, шеврон, ряд действий и версия 0.19.0

Набор `single/collection` передаётся из адреса страницы явным параметром
`demo_sample` в запросе списка. `Referer` больше не используется: прокси/iframe
может его обрезать. В наборе 13 записей; исходная порционная отрисовка показывает
12, затем ещё одну по кнопке. Проверка выполняет реальный отданный `fetchLinks()`
без Referer, поэтому регрессия в передаче параметра ловится тестом.

Тумблер навигации — простой шеврон, повёрнутый для верхней мобильной панели.
На телефоне создание/тема/настройки находятся в одном flex-ряду высотой 40px,
а не в независимо позиционированных блоках. При изменении ширины или сворачивании
перемещаются исходные кнопки, не их копии; фокус сохраняется.

Сервер макета читает номер из корневого `VERSION` (0.19.0) и отдаёт его через
обычную конфигурацию. Основной `showAppVersion()` показывает в подвале v0.19.0.
Раньше строка `design preview` содержала пробел и отклонялась этим валидатором.
Номер изменён в исходниках, но публикация релиза/слияние PR не выполнялись.

```sh
node --test design/mono/server.test.mjs
```
