# Lanpaper — три варианта обновлённого интерфейса

Файлы: `design/prototypes/` · открыть `index.html` · один общий дизайн-слой на всех.

---

## Как посмотреть

| Файл | Что это |
|---|---|
| `prototypes/index.html` | оглавитель: три варианта, палитра, переключатель темы |
| `prototypes/a-library.html` | Вариант A «Библиотека» |
| `prototypes/b-streams.html` | Вариант B «Потоки» |
| `prototypes/c-console.html` | Вариант C «Пульт» |
| `tokens.css` | цветовые токены, тени, радиусы, типографика (светлая + тёмная) |
| `prototypes/shared.css` | общие компоненты: кнопки, поля, меню, бейджи, тосты, шторка, панель деталей |
| `prototypes/variant-*.css` | только то, что специфично для варианта |
| `prototypes/proto.js` | поведение: фильтры, поиск, сортировка, меню, выбор, табы, темы |
| `prototypes/media/` | 5 сгенерированных обоев для наполнения макетов |

Всё статическое: кликайте, вводите в поиск, открывайте меню, переключайте темы
(кнопка справа сверху или клавиша `T`), меняйте ширину окна. Никаких сборок и зависимостей.

## Сравнение

| | A «Библиотека» | B «Потоки» | C «Пульт» |
|---|---|---|---|
| **Кому** | домашний сервер, 10–60 ссылок | 100+ ссылок, много плейлистов | цифровые вывески, киоски, витрины |
| **Плотность** | низкая: крупные превью 16:9 | высокая: строка = ссылка | средняя: карточка-канал + панель |
| **Взгляд** | «что у меня есть» | «найти и изменить быстро» | «что сейчас на экране» |
| **Смена файла** | hover → «Заменить» | ⋯ → «Заменить файл» | кнопка в панели, всегда на виду |
| **Доступ** | в панели деталей, 4 карточки-варианта | инлайн-пилюля прямо в строке | сегменты в панели, один клик |
| **Массовые операции** | ✓ панель снизу | ✓ строка в шапке таблицы | — (не про это) |
| **Ротация** | вкладка «Плейлист» панели | ⋯ → «Плейлист и ротация» | прогресс-полоса на карточке + очередь в панели |
| **Мобильный** | 2 колонки плитки, панель — шторка снизу | карточки-строки, меню — bottom sheet | лента карточек, панель — шторка снизу |
| **Риск** | при 200 ссылках надо много листать | выглядит «производственно», меньше «вау» | избыточен, если экранов мало |

**Моя рекомендация:** A как основной интерфейс (он честно про контент и снимает
перегрузку карточки), C — как второй режим для тех, у кого 5–20 вывесок;
B имеет смысл, если у вас действительно сотни ссылок. Проще всего начать с A:
он переиспользует больше всего от текущей вёрстки.

## Что именно улучшено относительно текущего интерфейса

Ссылки — на пункты из `01-audit.md`.

| # | Проблема сейчас | Как решено |
|---|---|---|
| P1 | Создание, поиск и сортировка в одной капсуле; на мобильном капсула не липкая | Тулбар разведён на два уровня: заголовок со счётчиками и главный CTA «Новая ссылка» (+ меню «Из галереи»), ниже — отдельная строка поиска, чипсы-фильтры и сортировки. В A/B строка липкая на десктопе, на мобильном уходит в поток и не крадёт высоту |
| P2 | Меню «Загрузить» содержит «Добавить в плейлист» и «Версии» — не про загрузку | Везде: «Добавить/Заменить» = только способы (файл, URL, галерея). Плейлист, версии, статистика, доступ — отдельные пункты меню `⋯` и вкладки панели деталей |
| P3 | Красная кнопка «Удалить» всегда рядом с основной | Постоянной кнопки удаления нет: она в `⋯`, внизу, отделённая разделителем. В режиме выбора — отдельная кнопка «Удалить» с подтверждением |
| P4 | 5–7 контролов видны на каждой карточке одновременно | Принцип трёх слоёв: **покой** (превью, имя, мета) → **наведение** (Открыть, Заменить) → **клик** (панель: доступ, версии, плейлист, статистика). На тач-устройствах hover-слой заменён постоянными иконками |
| P5 | Нет массовых операций и фильтров | Режим выбора: сразу несколько ссылок → общий уровень доступа, закрепить, экспорт, удалить. Фильтры-чипсы (закреплённые, плейлисты, видео, LAN, токены, без файла) со счётчиками, которые пересчитываются при поиске |
| P6 | Кастомный `div`-селект + скрытый дубликат `<select>` | Нативные `<select>` и меню-кнопки. Меньше кода, работает с клавиатуры и в screen reader без хаков |
| P7 | Насыщенный закатный акцент перетягивает внимание с обоев | Акцент — спокойный индиго (`#4F5AD6`, 5.6:1 с белым), используется точечно: главный CTA, фокус, выбранное. Градиент бренда остался логотипу |
| P8 | Мелочи | Счётчик «Всего» вынесен из поля поиска в заголовок; тема и «ещё» разведены; подписи у полей; пин-кнопка больше не появляется «только на hover»; статус ссылки виден сразу (бейдж уровня доступа с цветной точкой); у ссылок без файла — явное состояние и кнопка загрузки |

Дополнительно появилось то, чего не было:

* **Статус и здоровье ссылок.** В A — бейджи на превью; в C — пульс, «в эфире»,
  «нет обращений», прогресс ротации и счётчик в правильном месте.
* **Единая панель деталей** вместо модалки с четырьмя секциями: вкладки Обзор /
  Версии / Плейлист / Статистика, на мобильном — шторка снизу.
* **Осмысленные пустые состояния** и подтверждения через тосты.
* **Хорошая клавиатура:** `Ctrl/Cmd+F` — поиск, `Ctrl/Cmd+G` — вид, `T` — тема,
  `Esc` — закрыть меню и панель, всё с видимым фокус-рингом.

## Адаптивность: как ведут себя 360 px и 1440 px

| | Мобильный (≤768 px) | Десктоп (≥1024 px) |
|---|---|---|
| Каркас | одна колонка, сайдбар B превращается в строку чипсов | сайдбар B фиксирован, A/C — центр + панель |
| Превью | 16:9, 2 плитки в ряд (A) | 3–5 плиток (A), таблица (B), каналы (C) |
| Действия карточки | постоянные иконки + `⋯` | hover-слой + `⋯` |
| Меню | bottom sheet на всю ширину | поповер у кнопки, сам разворачивается вверх у нижней кромки |
| Панель деталей | шторка снизу с «ручкой», закрывается по скриму и `Esc` | колонка 400 px (C) / выезжающая панель 460 px (A) |
| Тач-таргеты | кнопки 44 px, иконочные 40 px, поля ввода 16 px (без зума на iOS) | 32–40 px |
| Массовые действия | плавающая панель у нижнего края | панель/строка в шапке списка |

## Что я проверил

Браузера в песочнице нет, поэтому визуальную проверку я заменил на техническую:

1. **Структура** — HTML разобран парсером: незакрытых и лишних тегов нет; фигурные
   скобки в CSS сбалансированы; `proto.js` проходит `node --check`.
2. **Поведение** — все страницы выполнены в DOM-окружении, клики сыграны:
   фильтры (скрылось 6 из 7), поиск (нашёл 1), открытие/закрытие меню, режим выбора
   и счётчик, массовые действия, сортировка, переключение вида, табы панели,
   выбор канала в C. Ошибок JS нет. По ходу нашёл и починил табы, которые не
   переключали панели.
3. **Доступность** — нет дублей `id`, у всех картинок `alt`, у всех кнопок есть имя,
   все декоративные иконки `aria-hidden`, все поля подписаны.
4. **Контраст** — пары посчитаны скриптом, см. таблицу выше.

**Проверьте глазами** — я не видел макеты отрендеренными, поэтому что-то может
«съехать» на нестандартной ширине. Скажите, где не так — поправлю точечно.
