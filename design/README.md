# Дизайн-стенд админки

Материалы UI/UX-работы над админ-панелью. Это **не код приложения**: ничего из
`design/` не отдаётся сервером (маршрут `/static/` до сюда не дотягивается), а
каталог исключён из контекста сборки Docker.

| Файл | Что внутри |
| --- | --- |
| `01-audit.md` | Разбор интерфейса 0.12.x: проблемы P1–P8, предложение по палитре, построчный разбор присланного макета |
| `02-variants.md` | Четыре варианта редизайна, отличия, адаптивность, проверки |
| `03-decision.md` | Как выбирали: две оси, сравнение по задачам, что вошло в синтез и что сознательно нет |
| `04-final.md` | Финальный макет и его итерации |
| `05-app.md` | Перенос макета в приложение — **откатан в 0.12.1**, см. баннер в начале файла |
| `tokens.css` | Общие токены: палитра, светлая и тёмная темы, контраст WCAG AA |
| `prototypes/` | Кликабельные макеты (A «Библиотека», B «Потоки», C «Пульт», D «Разделы», `final`, `final2`, палитры) |
| `preview.py` | Статический сервер для стенда |

## Статус

Редизайн был перенесён в админку и опубликован как **0.13.0**, но заметно сломал
интерфейс, поэтому в **0.12.1** представление откатано ровно к 0.12.0. Макеты
сохранены: следующая попытка должна начинаться с них, а не с нуля.

## Как посмотреть

```bash
cd design && python3 preview.py   # стенд с прототипами
```

Живую админку показывает `go run .` из корня репозитория (нужен `data/` с
`wallpapers.json`) — `/admin`.

Прежде чем снова переносить оформление в `main`, его нужно посмотреть глазами в
настоящем браузере: jsdom и разбор CSS-каскада не ловят поломки раскладки.
Минимум — десктоп, планшет и телефон, обе темы, длинная библиотека и пустая.
