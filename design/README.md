# Дизайн-стенд админки

Материалы UI/UX-работы над админ-панелью. Это **не код приложения**: ничего из
`design/` не отдаётся сервером (маршрут `/static/` до сюда не дотягивается), а
каталог исключён из контекста сборки Docker.

| Файл | Что внутри |
| --- | --- |
| `index.html` | Шапка стенда: ссылки на актуальный макет и на историю прототипов |
| `v2/` | **Актуальный макет «Lanpaper 2.0»** — админка, витрина на трёх ширинах, токены, компоненты, проверка контраста, сборка одним файлом |
| `06-redesign-v2.md` | Разбор 0.12.1 (P1–P12), принципы, спецификация, доступность, контраст, изменения поведения (11-бис), план переноса |
| `01-audit.md` | Разбор интерфейса 0.12.x: проблемы P1–P8, предложение по палитре, построчный разбор присланного макета |
| `02-variants.md` | Четыре варианта редизайна, отличия, адаптивность, проверки |
| `03-decision.md` | Как выбирали: две оси, сравнение по задачам, что вошло в синтез и что сознательно нет |
| `04-final.md` | Финальный макет 1.0 и его итерации |
| `05-app.md` | Перенос макета 1.0 в приложение — **откатан в 0.12.1**, см. баннер в начале файла |
| `tokens.css` | Общие токены макета 1.0: палитра, светлая и тёмная темы, контраст WCAG AA |
| `prototypes/` | Прежние кликабельные макеты (A «Библиотека», B «Потоки», C «Пульт», D «Разделы», `final`, `final2`, палитры) |
| `preview.py` | Статический сервер для стенда |

## Статус

- Макет 1.0 переносился в админку как **0.13.0**, сломал раскладку и был откатан в
  **0.12.1**. Прототипы сохранены в `prototypes/`.
- **Актуальная работа — `v2/` (Lanpaper 2.0)**: интерфейс собран заново от задач,
  пять спокойных палитр, контраст проверяется скриптом, есть витрина на трёх
  ширинах. Макет отвечает и на то, чего в 0.12.1 не было: порционная отрисовка
  библиотеки, состояние ошибки загрузки, добавление медиа по ссылке и из файлов
  сервера, массовая смена доступа, видимый предел плейлиста. В `admin.html`
  **не переносился** — перенос это отдельный шаг по плану из
  `06-redesign-v2.md`, раздел 12, а список изменений поведения — раздел 11-бис.
- Первая попытка сломалась на том, что оформление влили без просмотра в настоящем
  браузере. Порядок для второй попытки: макет → просмотр глазами на десктопе,
  планшете и телефоне в обеих темах → перенос по шагам → чек-лист из раздела 12.

## Как посмотреть

```bash
cd design && python3 preview.py        # стенд целиком, http://localhost:8000/
```

Прямые адреса:

- `/design/index.html` — шапка стенда;
- `/design/v2/index.html` — макет Lanpaper 2.0 (кликается);
- `/design/v2/screens.html` — тот же экран на 1440 / 834 / 390 px;
- `/design/v2/standalone.html` — макет одним файлом, без внешних запросов;
- `/design/prototypes/index.html` — прежние прототипы 1.0.

Живую админку показывает `go run .` из корня репозитория (нужен `data/` с
`wallpapers.json`) — `/admin`.

## Проверки

```bash
node design/v2/tools/check.mjs     # контраст пяти палитр в двух темах: 120 пар
node design/v2/tools/check.mjs --table
```

Проверки запускаются в песочнице и в репозиторий не попадают: состояния
интерфейса в jsdom (`checks.mjs` — 33 утверждения, `flows.mjs` — 25, оба по
странице макета и по сборке одним файлом), правила раскладки и CSS
(`css-check.mjs` — 50), сама сборка (`file-check.mjs` — 30), аудит классов
(`class-audit.mjs`), замеры (`perf.mjs`, `leak.mjs`), а также `html-validate` и
`stylelint`. Их результаты описаны в `06-redesign-v2.md`. Рисовать
пиксели они не умеют: внешний вид смотреть глазами.
